How this prototype works

This prototype is a fast signal checker for potential BNB Chain arbitrage, not an auto-trading bot.

Pipeline

  1. Loads a watchlist of BNB Chain tokens (CAKE, WBNB, ETH, ADA, DOGE, DOT, XRP).
  2. Fetches reference USD prices from CoinGecko (cached for a few seconds). If CoinGecko fails, the last good prices are reused for a few minutes and tagged stale.
  3. Requests two KyberSwap aggregator quotes per token against USDT, both sized at the same USD amount (QUOTE_NOTIONAL_USD, $1,000 by default): a sell quote (token → USDT) gives the DEX bid, a buy quote (USDT → token) gives the DEX ask.
  4. Computes the spread in both directions, keeps the better one, and subtracts configured trade costs.
  5. Flags the row as Opportunity when the spread exceeds cost + minimum profit.

Results are cached on the server for about 10 seconds and shared by everyone viewing the dashboard.

Columns

CEX
CoinGecko USD reference price. A stale tag means CoinGecko is currently failing and the last good price is shown.
DEX bid / DEX ask
USDT per token received when selling / paid when buying on the DEX. Both already include pool fees and price impact for the quoted size.
Direction
Buy DEX → sell CEX: spread = (CEX − ask) / ask.
Buy CEX → sell DEX: spread = (bid − CEX) / CEX.
Spread %
Gross edge of the better direction. Negative means neither direction is profitable.
Net %
Spread minus TRADE_COST_PCT.
Status
Opportunity when spread > TRADE_COST_PCT + MIN_PROFIT_PCT (0.25% + 0.10% by default). Check data when the spread is implausibly large (beyond MAX_PLAUSIBLE_SPREAD_PCT, 20% by default), which usually means a data error rather than a real opportunity.

Limitations

  • CoinGecko is an aggregated reference price, not an executable order book; it can lag the market.
  • Gas, CEX fees, withdrawal/bridge costs and transfer time are only covered by TRADE_COST_PCT.
  • The spread is valid for the quoted size only; larger trades get worse prices.

Use it to prioritize candidates for deeper execution checks (slippage, gas, latency, and routing quality).
